# Acme Pulse Product Overview

Acme Pulse is a product analytics platform. Teams use it to track user behavior, build dashboards, and run funnel, retention, and cohort analyses.

## Core features

- **Event tracking** with SDKs for JavaScript, iOS, Android, Python, Go, and a REST API.
- **Dashboards v2**: drag-and-drop dashboards with real-time tiles (replaces Reports v1).
- **Funnels and retention**: conversion funnels with up to 20 steps; retention curves by cohort.
- **Experiments**: A/B test analysis with sequential testing.
- **Alerts**: anomaly alerts delivered to Slack, email, or PagerDuty.
- **Warehouse sync** (Enterprise): nightly sync to Snowflake or BigQuery.

## Coming soon

- **AI Insights** (beta Nov 12, 2026): natural-language questions over your analytics, automatic anomaly explanations.

## Ideal customers

B2B and B2C SaaS companies with 20-2,000 employees. Main competitors: Amplitude, Mixpanel, PostHog.

## Key differentiators

- Unlimited dashboard seats on every plan.
- EU data residency.
- Query engine returns 95% of queries in under 2 seconds.
